# Transaction Explorer

Aplicación en Python y Streamlit para normalizar, validar y explorar transacciones de distintas fuentes.

El código, las instrucciones de instalación y la documentación están en [transaction-explorer](transaction-explorer/README.md).

Los archivos `transacciones_validas.json`, `transacciones_invalidas.json` y `transacciones_mixtas.json` contienen ejemplos para importar desde la aplicación.
